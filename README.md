# Expense Tracker - Personal Finance iOS App

A sleek personal budgeting and expense tracking iOS application powered by SwiftUI and CoreData persistence for tracking daily spending and financial summaries.

---

## 🛠️ Tech Stack & Architecture
`SwiftUI` `CoreData` `MVVM` `Charts & Metrics` `Swift`

- **Platform:** iOS 16.0+
- **Language:** Swift 5.10+
- **Framework:** SwiftUI
- **Architecture:** MVVM / Clean Architecture

---

## ✨ Key Features
- Persistent expense logging with CoreData PersistenceController
- Category breakdown (Food, Entertainment, Bills, Transport, etc.)
- Dashboard overview displaying current balance, total income, and total expenses
- Date-based filtering and transaction history view

---

## 🚀 Getting Started

### Prerequisites
- macOS Sonoma or newer
- Xcode 15.0 or newer
- iOS Simulator or physical device running iOS 16+

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Devendrakumar16/ExpenseTracker-iOS.git
   cd ExpenseTracker-iOS
   ```
2. Open the project in Xcode:
   ```bash
   open *.xcodeproj 2>/dev/null || open *.xcworkspace
   ```
3. If CocoaPods is used:
   ```bash
   pod install
   open *.xcworkspace
   ```
4. Select your target simulator (e.g., iPhone 15 Pro) and press `Cmd + R` to build and run!
